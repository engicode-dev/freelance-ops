# Freelance Ops 🚀

Личный менеджер для фрилансера, работающий полностью локально. 
Приложение объединяет трекер задач, учёт финансов, таймер Pomodoro и личный дневник в одном тёмном интерфейсе.

## ✨ Возможности
- **Задачи и Клиенты:** Учёт задач с дедлайнами, приоритетами и привязкой к клиентам.
- **Финансы:** Разделение доходов на активные и пассивные. Автоматический расчёт эффективной ставки в час.
- **Таймер и Pomodoro:** Запуск таймера на задачу (25 минут), сохранение заметок о том, на чём вы остановились.
- **Дневник:** Планирование личных задач (учёба, отдых) и ведение заметок по дням.
- **Графики:** Визуализация доходов по месяцам и соотношения активного/пассивного дохода с помощью `matplotlib`.
- **Два интерфейса:** Графический интерфейс (GUI) на базе `ttkbootstrap` и полноценный интерфейс командной строки (CLI).

## 🛠️ Технологии
- Python 3.10+
- Tkinter + ttkbootstrap (GUI)
- SQLite (база данных)
- Matplotlib (графики)

## 🚀 Установка и запуск (Linux)

На данный момент доступна сборка в виде одного бинарного файла (x86_64).

1. Скачайте архив `FreelanceOps-linux.zip` из раздела **Releases** (справа на странице репозитория).
2. Распакуйте его в удобную папку (например, `~/Applications/`).
3. Сделайте файл исполняемым:
   ```bash
   chmod +x FreelanceOps
   ```
4. Запустите приложение
    ```bash
    ./FreelanceOps
    ```
   (Файл базы данных income.db создастся автоматически рядом с программой при первом запуске).

## Запуск исходного кода

    ```bash
    git clone https://github.com/ваш_ник/freelance-ops.git
    cd freelance-ops
    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python main.py
    ```
